# bennijaeger.github.io

Personal academic website of Benjamin Jäger, Department of Mathematics and Computer Science, University of Southern Denmark: <https://bennijaeger.github.io>.

Built with [Jekyll](https://jekyllrb.com/) and the [multi-language-al-folio](https://github.com/george-gca/multi-language-al-folio) theme (MIT licence, see `LICENSE`). Deployed to the `gh-pages` branch by GitHub Actions (`.github/workflows/deploy.yml`).

Where the content lives:

| Content                                      | File                                                                   |
| :------------------------------------------- | :--------------------------------------------------------------------- |
| Site settings, social links                  | `_config.yml`                                                          |
| Subtitle, address, page descriptions, titles | `_i18n/en.yml`                                                         |
| About page text                              | `_i18n/en/_pages/about.md`                                             |
| News items                                   | `_news/`                                                               |
| Publications                                 | `_bibliography/papers.bib` (exported from INSPIRE-HEP, author 1272234) |
| Research topics                              | `_projects/`                                                           |
| Teaching                                     | `_pages/teaching.md`                                                   |
| CV                                           | `_data/en/cv.yml`                                                      |

Theme documentation: `INSTALL.md`, `CUSTOMIZE.md`, `FAQ.md`. Notes on the 2026 update: `CHANGES.md`.
